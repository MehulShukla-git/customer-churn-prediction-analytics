Data Quality Issues Handled

Issue Type Description & Resolution
Duplicates Found {{ dq_report.get('duplicate_rows', 0) }} exact duplicate rows and {{ dq_report.get('duplicate_customer_ids', 0) }} duplicate customer IDs. Removed exact duplicates and kept the most recent record for duplicate IDs.
Missing Values Imputed missing numerical data with the median to avoid outlier distortion. Categorical gaps were filled with an 'Unknown' category.
Inconsistent Categories Found overlapping categories (e.g., 'basic' vs 'Basic') in Plans and Contract types. Normalized all text strings to uppercase/lowercase standards.
Numerical Outliers Found {{ dq_report.get('age_range', {}).get('negatives', 0) }} negative ages and {{ dq_report.get('spend_range', {}).get('negatives', 0) }} negative spend values. Values outside logical bounds were capped (winsorized) at the 99th percentile or converted to NaN for median imputation.
Ambiguous Targets Rows with missing or unclear churn labels were dropped to prevent adding noise to the ML model.
